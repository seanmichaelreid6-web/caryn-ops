Email → Context Library

Drop email files straight from Outlook (.eml, .msg, or a .zip of them). Each one becomes its own folder holding a Markdown copy of the email, the original file, and every attachment in its original form — extracted from inside the email, so nothing has to be matched up by hand. Nothing is uploaded anywhere.

How to get the files out of Outlook
  1. One email: right-click it in the message list → Save as → Save as EML (in Outlook on the web it's Download → Download as EML). You can also drag the message straight into a folder.
  2. Many at once: select them all → Forward → Forward as attachment → send it to yourself. Open that email and click Download all — you get one .zip of emails. Drop the whole .zip here.
The saved .eml/.msg already contains every attachment, so there is no printing, no scanning and nothing to match by filename. Emails protected with encryption or "Do not forward" can't be saved this way — those still need to be handled by hand.
