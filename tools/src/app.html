Email PDF → Markdown

Drop a saved email PDF below. Each email gets its own folder — named Subject From Sender Month Day — inside the category you choose, with the Markdown file saved inside it. Add the email's attachments to the same folder and everything stays together. Nothing is uploaded anywhere.

Works with Outlook email PDFs, including image-only ones made by “Microsoft Print to PDF” (those are read with built-in OCR, which takes a few seconds per page). Tip: when printing from Outlook, choosing “Save as PDF” as the printer instead of “Microsoft Print to PDF” produces PDFs that convert faster and more accurately. Ambiguous numeric dates like 3/4/2026 are read as month/day (US style).
