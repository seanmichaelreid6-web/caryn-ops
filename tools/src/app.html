Email PDF → Markdown

Drop a saved email PDF below. It becomes a Markdown file named Subject - YYYY-MM-DD.md, dated to the latest message in the thread. Everything runs in your browser — nothing is uploaded anywhere.

Tuned for emails saved as PDF from Outlook (From / Sent / To / Subject headers). Other formats fall back to the PDF's own title and date. Ambiguous numeric dates like 3/4/2026 are read as month/day (US style).
