Outlook Email → Markdown Archive

Save or drag an email out of Outlook, then drop the resulting .eml or .msg file here. The tool creates a named folder containing the Markdown email and every real attachment automatically. PDF remains available as a fallback. Everything runs on this computer; nothing is uploaded.

Email home folder: not chosen yet Pick the folder that holds your category folders (Everest Emails, Billing Emails, and so on) — for example a folder on your Desktop. You only do this once.
New Outlook / Outlook on the web: open the message and choose More actions → Save as or Download; you can also drag it to your Desktop. Classic Outlook: open the message and choose File → Save As, or drag it to your Desktop. The saved .eml/.msg already contains its attachments, so do not save or print them separately.
